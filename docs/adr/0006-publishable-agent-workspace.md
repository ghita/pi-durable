# Publishable agent workspace

**Status:** Accepted

This repository will use a private, non-publishable workspace coordinator with four independently publishable packages under `packages/`: `server` (`@earendil-works/server`), `client-sdk` (`@earendil-works/client-sdk`), `agents` (`@earendil-works/agents`), and `contracts` (`@earendil-works/contracts`). The agents package contains agent implementations rather than an authoring SDK; its initial contents include Deep Research and Simple Chat. The client-sdk package provides the reusable client SDK and `agent-cli`; the agent-authoring SDK and `agent-server` executable are provided by the server package. Shared public API types and schemas live in the contracts package, consumed by both server and client-sdk. The server catalog will support both relative module paths for monorepo development and package-export references for deployments that install published agent packages, so neither workflow is mandatory. Root scripts coordinate monorepo development and are not the deployed-package interface.
